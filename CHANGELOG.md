# История изменений

## 2026-11-24

- Сайт стал мобильным веб-приложением: отдельные страницы разделов, плавные переходы внутри одной вкладки, кнопка «назад», нижняя панель вкладок.
- Страница для каждого растения с трекером «Мой стаканчик». Короткие QR-ссылки `/q/<код>` ведут на неё.
- Админка: разделы, букеты, растения, вопросы, отзывы, QR-коды (SVG/PNG для печати), контакты и SEO. Открывается по секретному адресу; без бэкенда работает в демо-режиме.
- Микро-бэкенд на Node.js без зависимостей; конфигурация nginx и systemd для своего сервера.
- SEO: пререндер всех страниц, canonical, Open Graph, schema.org, sitemap.xml, robots.txt.
- Своя страница 404.
- Тесты (Vitest), запуск тестов в CI.

## 2026-11-03

- Лицензия, описание проекта, политика безопасности и правила работы с репозиторием.
- Тексты лицензий сторонних библиотек и шрифтов публикуются вместе с сайтом, ссылка - в подвале.

## 2026-11-01

- 3D-стаканчик работает на всех устройствах, включая телефоны.
- Заказ оформляется в Telegram готовым сообщением.
- Политика безопасности контента, проверка сохранённого заказа, защищённый CI, Dependabot.

## 2026-11-01 - первая версия

- Лендинг: главная с 3D-стаканчиком, «О нас», «О стаканчиках», «Букеты», «Семечки», «Контакты».
- Страницы букетов и семечек, заказ «букет + семечко».
- Автоматический деплой на GitHub Pages.
