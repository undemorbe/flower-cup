# Flower Cup

**Букет, который продолжает жить.**

Flower Cup - эко-стартап, который продаёт букеты в биоразлагаемых крафтовых стаканчиках вместо пластиковой упаковки и вазы. На дне каждого стаканчика лежит конвертик с семенами: когда букет отцветёт, в этом же стаканчике можно вырастить новое растение, а потом посадить его в землю вместе со стаканчиком.

Сайт: https://undemorbe.github.io/flower-cup/ · Заказы: [Telegram @polyvinylchlorid](https://t.me/polyvinylchlorid)

## О продукте

Обычный букет - это цветы плюс плёнка, лента, коробка и ваза. Почти всё, кроме цветов, через неделю отправляется в мусор. Мы убираем этот слой:

- **Стаканчик вместо вазы.** Цветы сразу стоят в воде в плотном стаканчике из крафт-картона.
- **Без пластика и лишней упаковки.** Клиент платит за цветы, а не за обёртку, поэтому букет обходится дешевле.
- **Вторая жизнь.** Семечко на дне превращает отцветший букет в начало нового растения.

### Жизнь одного стаканчика

1. **Стоит как в вазе.** Вода наливается прямо в стаканчик.
2. **Букет отцвёл.** Цветы - в компост, стаканчик остаётся.
3. **Семечко на дне.** В стаканчик насыпают землю и сеют семена из конвертика.
4. **Прямо в землю.** Окрепший росток сажают в горшок или грунт вместе со стаканчиком, корни не тревожат.

### Ассортимент

- **Букеты:** «Полевые цветы», «Роза в поле», «Лаванда», «Подсолнух».
- **Семена на выбор:** базилик, подсолнечник, ромашка аптечная, лаванда, василёк синий, настурция.

Клиент сам выбирает, какое семечко положить в стаканчик. Заказ оформляется в Telegram: сайт формирует сообщение с выбранным букетом и семенами.

## Сайт

Лендинг с каталогом и страницами товаров.

- **Главная:** интерактивный 3D-стаканчик с букетом. Его можно вращать, а кнопка «Посадить стаканчик» показывает, как стаканчик уходит в землю и из него вырастает росток. Дальше идут разделы «О нас», «О стаканчиках», «Букеты», «Семечки», «Контакты».
- **Страница букета** `/bouquets/:slug`: состав, выбор семечка, уход, похожие букеты.
- **Страница семечка** `/seeds/:slug`: условия выращивания, пошаговая инструкция, добавление в букет.
- **Заказ:** выбранные букет и семечко сохраняются в браузере и отправляются в Telegram готовым сообщением.

Иллюстрации букетов и пакетиков семян нарисованы кодом (SVG), 3D-сцена собрана процедурно на three.js. Внешних изображений и моделей нет.

### Стек

- [Vue 3](https://vuejs.org) + [Vue Router](https://router.vuejs.org), сборка [Vite](https://vite.dev)
- [three.js](https://threejs.org) для 3D-сцены, загружается отдельным чанком
- Шрифты Cormorant Garamond, Rubik и Marck Script через [Fontsource](https://fontsource.org), раздаются с нашего домена
- Хостинг на GitHub Pages, деплой через GitHub Actions

## Разработка

Нужен Node.js 20 или новее.

```bash
npm install
npm run dev       # dev-сервер на http://localhost:5173
npm run build     # продакшен-сборка в dist/
npm run preview   # посмотреть собранный сайт локально
```

### Структура

```
src/
  data/catalog.js         букеты, семена, составы, цены, инструкции по уходу
  data/site.js            контакты и ссылка на Telegram
  styles/tokens.css       палитра, шрифты, отступы - единственный источник цветов
  three/cupScene.js       3D-сцена: стаканчик, букет, посадка, вращение
  components/             секции главной, шапка, подвал, панель заказа
  components/art/         SVG-иллюстрации букетов, пакетиков и стадий
  views/                  главная, страница букета, страница семечка
  composables/useOrder.js заказ: состояние, сохранение, ссылка в Telegram
scripts/
  spa-fallback.mjs        404.html и .nojekyll для GitHub Pages
  third-party-licenses.mjs  собирает лицензии зависимостей в dist/
```

### Как поменять контент

- **Цены, составы, тексты товаров** - `src/data/catalog.js`. Цена `null` показывается как «Цена уточняется».
- **Контакты** - `src/data/site.js`. Телефон, почта и строка о доставке пока заглушки, их нужно заменить до публичного запуска.
- **Цвета и шрифты** - только через токены в `src/styles/tokens.css`. В компонентах используются `var(--color-...)`, а не hex-значения.

## Деплой

Workflow `.github/workflows/deploy.yml` собирает сайт на каждый push в `main` и публикует его на GitHub Pages. Pull request только собирается, без публикации.

Один раз в настройках репозитория: **Settings → Pages → Source: GitHub Actions**.

Base-путь `/<repo>/` подставляется автоматически. Для своего домена поменяйте `BASE_PATH` в workflow на `/` и добавьте файл `public/CNAME` с доменом.

## Безопасность

Сайт статический: без сервера, форм, оплаты, cookie и аналитики. В сборку встроена политика безопасности контента (CSP), данные из браузерного хранилища проверяются, а GitHub Actions закреплены по SHA коммита. Как сообщить об уязвимости - в [SECURITY.md](SECURITY.md).
